# README artwork

- `wordmark.svg`: original editable vector lettering, drawn on a 5×7 square-pixel grid.
  Navy, ivory, cyan, brass, and coral tie the title to the sponsor card and office palette.
- `sponsor.png`: promotional pixel-art illustration created with the built-in imagegen tool,
  then refined with the same tool to simplify the background. It is not a software screenshot.
  The scene was generated without reference to or input from existing game sprites.
- `sponsor-prompt.txt`: the generation prompt and final refinement prompt used for the illustration.

The sponsor card links to `docs/sponsorship.md` while the maintainer's Sponsors account is being
set up. Once the listing accepts sponsorships, point the card and text link directly to the
verified listing and update the status copy. Keep the image's accessible description in README.md.

Actual application screenshots and their artwork credits are documented in
[`../screenshots/README.md`](../screenshots/README.md).
