# Sponsorship

Sponsorship is prepared for [@montagao](https://github.com/montagao). GitHub Sponsors was not
active when this repository was prepared, so donations are not currently available here.

Maintainer setup:

1. Activate the account at https://github.com/sponsors/accounts.
2. Confirm https://github.com/sponsors/montagao accepts sponsorships.
3. The prepared `.github/FUNDING.yml` enables GitHub's Sponsor button after the listing is live
   and the file is on the default branch. Replace this status text and link the README directly
   to that verified destination. Enable the sponsorship option in repository settings if needed.

To use another provider, replace FUNDING.yml with the verified account or custom HTTPS URL.
Sponsorship supports maintenance; it does not promise support response times or particular features.
