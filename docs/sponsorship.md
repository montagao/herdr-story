# Keep the office lights on

![Sponsor me — support @montagao and Herdr Story](art/sponsor.png)

Herdr Story is built by [@montagao](https://github.com/montagao). Sponsorship helps support
maintenance, polish, and continued development of the little office.

**GitHub Sponsors is being set up; donations are not live yet.** This page will link to the
verified listing once it opens. In the meantime, a star, a useful bug report, or a contribution
is a welcome way to help.

[Star the repository](https://github.com/montagao/herdr-story) ·
[Report a bug or suggest an idea](https://github.com/montagao/herdr-story/issues) ·
[Contribute](../CONTRIBUTING.md)

<details>
<summary>Maintainer: activate the Sponsor button</summary>

1. Activate the account at https://github.com/sponsors/accounts.
2. Verify https://github.com/sponsors/montagao accepts sponsorships.
3. Point the README card and sponsor text directly to that listing; update the status on both pages.
4. The prepared `.github/FUNDING.yml` supplies the GitHub Sponsor button. Enable the sponsorship
   option in repository settings if needed.

For another provider, replace FUNDING.yml with the verified account or custom HTTPS URL.
Sponsorship does not promise support response times or particular features.

</details>
